# PixelSmith Quiz Funnel: Setup & Integration Guide

This document provides instructions for setting up and integrating the PixelSmith Quiz Funnel component into your Next.js application.

## Overview
This quiz funnel component is designed to capture leads for PixelSmith by offering a personalized website assessment quiz. It includes a landing page, 4-question quiz interface, and results page with consultation booking CTA.

## Features
- ✅ Responsive design optimized for mobile and desktop
- ✅ Progress tracking and smooth transitions
- ✅ Email capture and lead generation
- ✅ Personalized results based on quiz answers
- ✅ Analytics event tracking (Google Analytics ready)
- ✅ Supabase integration for data storage
- ✅ WCAG 2.1 accessibility compliance

## Setup Instructions

### 1. Supabase Database Setup

The quiz funnel stores submission data in a Supabase table named `quiz_results`.

**Action Required:** Execute the following SQL script in your Supabase SQL Editor to create the necessary table and indexes.

\`\`\`sql
-- SQL script to create the quiz_results table in Supabase

CREATE TABLE IF NOT EXISTS quiz_results (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  email TEXT NOT NULL CHECK (email ~* '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$'),
  business_name TEXT,
  challenge TEXT NOT NULL,
  business_type TEXT NOT NULL,
  budget TEXT NOT NULL,
  goal TEXT NOT NULL,
  submitted_at TIMESTAMPTZ DEFAULT NOW() NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW() NOT NULL
);

COMMENT ON COLUMN quiz_results.email IS 'Email address of the user who took the quiz.';
COMMENT ON COLUMN quiz_results.business_name IS 'Optional business name provided by the user.';
COMMENT ON COLUMN quiz_results.challenge IS 'User''s answer to the "biggest website challenge" question.';
COMMENT ON COLUMN quiz_results.business_type IS 'User''s answer to the "business type" question.';
COMMENT ON COLUMN quiz_results.budget IS 'User''s answer to the "monthly marketing budget" question.';
COMMENT ON COLUMN quiz_results.goal IS 'User''s answer to the "top goal" question.';
COMMENT ON COLUMN quiz_results.submitted_at IS 'Timestamp when the user submitted the quiz.';

CREATE INDEX IF NOT EXISTS idx_quiz_results_email ON quiz_results(email);
CREATE INDEX IF NOT EXISTS idx_quiz_results_submitted_at ON quiz_results(submitted_at DESC);

-- It's good practice to enable Row Level Security (RLS) on your tables.
-- The API route uses the service_role_key, which bypasses RLS for inserts.
-- ALTER TABLE quiz_results ENABLE ROW LEVEL SECURITY;
-- CREATE POLICY "Allow service role to insert" ON quiz_results FOR INSERT TO service_role WITH CHECK (true);
-- CREATE POLICY "Allow service role to select" ON quiz_results FOR SELECT TO service_role USING (true);

\`\`\`
*Find this script also at `scripts/002-create-quiz-results-table.sql`.*

### 2. Environment Variables

Ensure the following environment variables are configured in your Next.js project (e.g., in `.env.local` for local development and in your Vercel project settings for deployment):

\`\`\`env
# Supabase Credentials
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_public_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key # For server-side operations like in the API route

# Google Analytics (Optional)
NEXT_PUBLIC_GA_ID=your_google_analytics_4_measurement_id
\`\`\`

Replace placeholder values with your actual Supabase project URL, keys, and Google Analytics ID.

### 3. Font Setup

The quiz funnel uses 'VT323' for pixelated headings/buttons and 'Inter' for body text.

**Action Required:**
   - Ensure these fonts are included in your project. If not already set up globally:
     Add to your `app/layout.tsx` or global CSS:
     \`\`\`html
     <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&family=VT323&display=swap" rel="stylesheet">
     \`\`\`
   - Update your `tailwind.config.ts` to include these font families:
     \`\`\`javascript
     // tailwind.config.ts
     module.exports = {
       // ... other configurations
       theme: {
         extend: {
           fontFamily: {
             'mono': ['VT323', 'monospace'], // For pixelated text
             'sans': ['Inter', 'sans-serif'],  // For body text
           },
           colors: {
             'brand-black': '#1A1A1A',
             'brand-green': '#2E7D32',
             'brand-green-hover': '#4CAF50',
             'brand-light-gray': '#B0BEC5',
             'brand-gold': '#FFD700',
           }
         },
       },
       // ... other configurations
     };
     \`\`\`
     *Note: The component uses these specific hex codes directly in Tailwind classes like `bg-[#1A1A1A]`. Defining them in `tailwind.config.ts` allows for cleaner class names like `bg-brand-black`.*

### 4. Google Analytics Integration (Optional)

If you want to track quiz events with Google Analytics:

**Action Required:**
   - Add your `NEXT_PUBLIC_GA_ID` to your environment variables.
   - Ensure Google Analytics (GA4) is initialized in your application, typically in `app/layout.tsx`. Example:
     \`\`\`tsx
     // app/layout.tsx
     import Script from 'next/script';

     export default function RootLayout({ children }: { children: React.ReactNode }) {
       return (
         <html lang="en">
           <head>
             {/* Google Analytics Scripts */}
             {process.env.NEXT_PUBLIC_GA_ID && (
               <>
                 <Script
                   strategy="afterInteractive"
                   src={`https://www.googletagmanager.com/gtag/js?id=${process.env.NEXT_PUBLIC_GA_ID}`}
                 />
                 <Script
                   id="google-analytics"
                   strategy="afterInteractive"
                   dangerouslySetInnerHTML={{
                     __html: `
                       window.dataLayer = window.dataLayer || [];
                       function gtag(){dataLayer.push(arguments);}
                       gtag('js', new Date());
                       gtag('config', '${process.env.NEXT_PUBLIC_GA_ID}', {
                         page_path: window.location.pathname,
                       });
                     `,
                   }}
                 />
               </>
             )}
           </head>
           <body>{children}</body>
         </html>
       );
     }
     \`\`\`
The `QuizFunnel` component already includes `trackEvent` calls for:
   - `quiz_started`
   - `quiz_completed`
   - `consultation_cta_clicked`
   - `download_report_cta_clicked`
   - `quiz_submission_error`

### 5. Component Usage

To use the quiz funnel, import and render the `QuizFunnel` component on a page (e.g., `app/quiz/page.tsx`).

\`\`\`tsx
// app/quiz/page.tsx
import QuizFunnel from "@/components/quiz-funnel";
import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Free Website & Marketing Quiz | PixelSmith",
  description: "Discover your website's growth potential in 2 minutes! Take our free quiz for a personalized action plan.",
  // ... other SEO metadata
};

export default function QuizPage() {
  return <QuizFunnel />;
}
\`\`\`
The `QuizFunnel` component is designed to take up the full screen.

### 6. API Route

The component makes a POST request to `/api/quiz-results` to save data. Ensure the `app/api/quiz-results/route.ts` file is in place and correctly configured to interact with your Supabase instance.

This setup should get your PixelSmith Quiz Funnel up and running!

### 7. Customization

#### Quiz Questions
Modify the `quizQuestions` array in `quiz-funnel.tsx` to customize questions and options.

#### Results Logic
Update the `getPersonalizedResults()` function to customize recommendations based on answers.

#### Styling
The component uses Tailwind CSS with PixelSmith brand colors:
- Black: `#1A1A1A` (bg-black)
- Dark Green: `#2E7D32` (bg-green-700)
- Light Gray: `#B0BEC5` (text-gray-400)
- Gold: `#FFD700` (text-yellow-400)

### 8. Analytics Events

The component tracks these events:
- `quiz_started` - When user starts the quiz
- `quiz_completed` - When user completes the quiz
- `consultation_clicked` - When user clicks consultation CTA
- `download_clicked` - When user clicks download CTA
